推荐流程：在电脑或手机浏览器里打开 → 导出 JSON 文件 → 用微信/蓝牙/数据线传到另一台设备 → 在那里打开本页面用「导入备份（JSON）」读入。小规模数据也可以直接复制文本。

使用说明

1. 录入：点底部「＋」，填写设备名称（必填）以及上次检修日期、轴承型号、螺丝大小、检修经验总结等，点「保存记录」。
2. 查询：在「查询」页输入任意关键字（设备名、型号、轴承号、螺丝规格、经验里的词都可以），输入即搜。
3. 没有怎么办：若没有直接匹配，会明确提示「没有查到」，并把模糊相似的记录列在下面供参考；也可一键用该关键字新建记录。
4. 备份：数据存在本浏览器里。换设备或清理浏览器前，先点「导出备份（JSON）」，在新设备上「导入备份」即可。
5. 手机使用（重要）：不要用微信/QQ 内置的预览窗口打开，那里会禁止本地存储，会出现「界面能看、按钮点不动」的问题。正确做法：在微信里点右上角「⋯」→ 用其他应用打开 → 选 Chrome / 系统浏览器；或先把文件保存到手机「文件 / 下载」目录，再从浏览器里打开。
6. 外观：在同一页上方可切换背景颜色（浅色 / 深色）与字号大小（小 / 中 / 大），选择后立即生效并自动记住。
7. 换手机搬数据：用上方的「导出备份 / 系统分享 / 复制备份内容」，在新手机打开本页面后用「导入备份」或「从剪贴板粘贴导入」。

危险操作

「清空」只影响本浏览器，请先导出备份。
